# Repository Instructions

- After completing each change, create a corresponding Git commit to support tracking and rollback.
- After each change, write or update the relevant tests, and ensure that all tests and validation pass before delivery to the user.
- Whenever a document changes, update all corresponding language versions in the same commit and keep their meaning and scope consistent. English documents use the default filename; translated versions use a language suffix such as `.zh.md`.
