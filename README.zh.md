# xdoku

使用 Expo 與 TypeScript 在 Windows 開發的 iPhone 貓咪邏輯遊戲。名稱與美術尚未定案。

## 開發

使用 Node.js 22.16 或更新版本。在 `mobile` 執行 `npm ci`，再執行 `npm start`。在 iPhone 使用相容的 Expo Go 或開發建置。`npm run web` 可開啟瀏覽器版本。

以 `npm test`、`npm run typecheck` 與 `npm run lint` 驗證。測試涵蓋唯一解、區域連通性、確定性生成、UTC 每日種子及放置規則。仍須進行 iPhone 實機測試。

依賴稽核目前在 Expo CLI 間接使用的 node-forge／zod 套件中回報五項高嚴重性問題。相容的自動修正未能清除，發佈前須重新評估上游更新。

## 狀態與路線

已實作：自動選擇 7×7、8×8、9×9 或 10×10 唯一解棋盤、編號關卡、UTC 每日棋盤、單擊排除記號、雙擊放貓咪、衝突回饋、復原、揭示、重玩及本機儲存。不提供尺寸選擇器；由混合後的關卡／日期種子選擇尺寸，所以重玩同一關會保持棋盤，每位玩家的每日尺寸亦相同。目前介面為繁體中文。

可在棋盤上拖曳以快速編輯記號。從空白格開始，整次拖曳固定為加入記號；從排除記號開始，整次固定為清除記號。貓咪不會被改動，從貓咪開始拖曳不會塗改。快速拖曳會補上經過的格子，重複經過不會切換狀態，整次拖曳可一次復原。中斷拖曳會捨棄預覽。手指輕微移動仍視為點擊。觸摸棋盤時會暫停頁面捲動，請從棋盤外捲動頁面。螢幕閱讀器可使用各格的切換記號／貓咪輔助動作。

每個色區使用十色調色盤中的獨有顏色。衝突以紅色外框及驚嘆號標示，並保留原本的色區底色。配色測試檢查兩兩 CIELAB 色差與記號對比；色覺差異的可用性仍需使用者測試。

每個新棋盤最多只有一個單格色區。擴張時會先讓其他色區至少達到兩格，完成後再檢查並排除仍然違規的候選。生成流程使用帶種子的隨機回溯法安排貓咪、擴張連通色區（隨機保留小色區作為大型棋盤的推理起點）、找到第二個解即停止的解題器，以及不猜測的推理驗收。推理包含單一候選，以及列、欄、色區的共同衝突排除。難度採啟發式評級：不需群組排除為簡單，使用 1–3 次為中等，4 次以上為困難。此評級仍需玩家測試校準；棋盤尺寸本身不代表難度。

一般關卡庫會排除旋轉、鏡像的八種變換與色區重新編號後相同的棋盤。每日棋盤由 UTC 日期與尺寸確定，不檢查歷史每日關卡是否重複。生成最多嘗試 5,000 個候選，超過會回報失敗。關卡庫會在記憶體快取，重新啟動後由種子重建。

第四版生成器會依模式、尺寸及含版本的棋盤 ID 分開儲存進度。第一至三版存檔仍保留在裝置，但不會套用到新版棋盤。上架前需加入解釋推理過程的提示、多語系、不依賴顏色的區域識別、原創素材與裝置測試，包括舊款 iPhone 的生成延遲。

排行榜需要可信任後端與分數驗證，並區分使用提示的紀錄。購買功能需要 Apple 商品、權益驗證及回復購買。目前兩項服務均未串接，不收取款項，也不提供虛構排名。

發佈需要 Apple Developer 與 Expo 帳號、正式 bundle identifier、EAS 設定、簽署、TestFlight 測試、隱私揭露、支援與隱私頁面、商店素材及送審。此原型尚未達到送審標準。請勿將憑證放入 Git。
